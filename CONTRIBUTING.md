# Contributing

This repository holds finished work: the Bachelor's thesis "Password- / Keyless authentication" by Mert Torun as deposited, and Raven One SimuLink, the program written for it in 2021. It is not developed further and takes no feature contributions.

## Corrections

Send a correction to the thesis, the code or the documentation by e-mail to [info@mtorun0x7cd.com](mailto:info@mtorun0x7cd.com), with the item, the location, the quoted text, the proposed correction and the evidence, and a note that you checked `ERRATA.md`. The README gives the details under Corrections. The repository takes no issues.

The text of the thesis changes only by errata: the deposited file stays as it is, and a confirmed error is added to `ERRATA.md`.

## Pull requests

The repository is archived and read-only on GitHub, so it takes no pull requests. The three appendix files under `src/` stay as the thesis prints them, defects included. Security reports follow [`SECURITY.md`](SECURITY.md).
